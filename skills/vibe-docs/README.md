# vibe-docs

Turns a raw one-line app idea into a complete, actionable `docs/` package
(BRD, PRD, ARCHITECTURE, DATA_MODEL, API_SPEC, DESIGN, SECURITY,
TEST_PLAN, DEPLOYMENT, SCOPE, DECISIONS) plus `prd.json` (the ralph task
list), hands-free — zero clarifying questions, every assumption recorded
in `docs/DECISIONS.md`.

Docs only. Does not write application code — `vibe-build` (sibling skill
in this pack) consumes the output.

## Use when

"turn my idea into a fullstack app", "build docs for my idea", "write the
prd and brd", "vibe coding", "give me an idea".
