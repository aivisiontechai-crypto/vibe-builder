# vibe-evolve

Self-improvement loop for the builder toolchain. Refreshes installed
skills, hunts for stronger/newer skills for every builder pipeline phase
via `find-skills`, installs only verified reputable candidates, and
records every change in `~/.agents/skills/LEDGER.md`.

Cadence-gated (default 14 days) unless explicitly requested. Never
installs unverified or unknown-source skills.

## Use when

"self improve", "evolve yourself", "upgrade your skills", "find better
skills", "keep your toolchain current".
